# Olympic Research Hub 🏋️‍♂️📊

**Olympic Research Hub** — интерактивная веб-платформа для библиометрического анализа, структурирования и поиска научного знания в области спортивной науки, подготовки атлетов и олимпийских дисциплин.

## 🌟 Основные возможности

* **🔎 Умный поиск и фильтрация:** Поиск по названиям, авторам, ключевым словам и специализированным категориям спортивной науки.
* **📊 Интерактивная аналитика:** Построение диаграмм категорий и динамики публикационной активности по годам в реальном времени (Chart.js).
* **📚 Академическое цитирование:** Автоматическая генерация готовых библиографических ссылок по стандартам **ГОСТ Р 7.0.100–2018** и **APA**.
* **⭐ Личные подборки:** Сохранение ключевых источников в избранное с использованием `localStorage`.
* **📥 Экспорт данных:** Выгрузка отфильтрованных результатов исследований в формате CSV для работы в MS Excel / SPSS.
* **🤖 Автоматический ETL-пайплайн:** Автоматический сбор, очистка и сборка датасетов через Python и GitHub Actions.
